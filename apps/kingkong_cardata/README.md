# Kingkong (`kingkong_cardata`)

iDrive 8 live data for Kingkong Tuning (M3 G81). Quiet Dials skin, bottom tabs, etanol %, Skicka-logg.

- **Engine** — Quiet Dials RPM/Boost, effekt, vridmoment, temps, battery, etanol as `Etanol XX %` / `Etanol -- %` (Fuel+Engine); probes 5939/5938/550D/F452/593A; Settings ethDebug; LPFP UDS fallback  
- **Fuel** — intake / fuel pressures / timing / boost with 5‑minute traces + etanol % (same sources)  
- **Trips** — trip computer and costs (currency default SEK)  
- **Transmission** — ZF 8HP read-only (experimental)  
- **Details** — engine unit values in groups  
- **Settings** — bar ends, fuel price, currency, Skicka-logg (30 min ringbuffer)  

Install via MGU Store from source `Amit-Gobil/kingkong` (see repo root README).
