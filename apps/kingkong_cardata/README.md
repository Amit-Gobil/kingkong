# Kingkong (`kingkong_cardata`)

iDrive 8 live data for Kingkong Tuning (M3 G81).

- **Engine** — RPM, boost, effekt, vridmoment (with peaks), speed/gear, oil, coolant, intake, battery  
- **Fuel** — intake / fuel pressures / timing / boost with 5‑minute traces  
- **Trips** — trip computer and costs (currency default SEK)  
- **Transmission** — ZF 8HP read-only (experimental)  
- **Details** — engine unit values in groups  
- **Settings** — bar ends, fuel price, currency  

Install via MGU Store from source `Amit-Gobil/kingkong` (see repo root README).
